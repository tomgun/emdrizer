# F-0005: Therapy session with stages, breaks, and targets - Acceptance Criteria

**Feature**: A structured therapy session mode with stages (preparation, BLS sets with breaks, closure) and optional targets (memories/situations/images to concentrate on) during bilateral stimulation.

**Research basis**: EMDR uses an 8-phase protocol; self-apps use a simplified flow. BLS is delivered in **sets** (e.g. 5–6 passes or ~30–60 s), then a **break** to check in. **Targets** = specific memory, thought, emotion, or situation the user holds in mind while following the moving target. Safe self-practice: distress 1–6; 7+ suggest professional support.

---

## Tests

### Unit Tests
- [ ] Session has at least: preparation stage, one or more BLS stages with configurable duration, breaks between BLS stages, closure stage.
- [ ] User can define a target (short label; optional image/placeholder) and see it before or during BLS.
- [ ] Break screen appears between BLS sets; user can continue when ready (button or auto-after minimum).

### Integration / E2E (if applicable)
- [ ] Full session flow: preparation → BLS → break → BLS → … → closure runs without getting stuck.
- [ ] Session works with all target views (sweeping light, KITT, therapist finger) and speed presets.

---

## Acceptance Criteria

### Session structure
- [ ] **AC-001**: A **session** can be started from the main screen (e.g. “Start session” or “Session mode”). Session comprises **stages** in order: **Preparation** → one or more **(BLS + Break)** blocks → **Closure**.
- [ ] **AC-002**: **Preparation stage**: Short intro; user can optionally set a **target** (see AC-006). Optionally show reminder that self-practice is for mild–moderate distress (1–6); 7+ suggest professional support. User proceeds to first BLS stage when ready.
- [ ] **AC-003**: **BLS stage**: Moving target runs for a configurable duration (e.g. 30 s, 60 s) or number of passes; then automatically transitions to a **break**.
- [ ] **AC-004**: **Break stage**: Target stops or pauses; screen shows a brief rest message (e.g. “Take a breath”, “How do you feel?”). User continues to next BLS stage or to closure via “Continue” (or optional auto-continue after a minimum break, e.g. 10 s).
- [ ] **AC-005**: **Closure stage**: Final message (e.g. “Session complete. Take your time.”); option to return to main screen or start another session.

### Targets (what to concentrate on)
- [ ] **AC-006**: User can define one or more **targets** for the session. A target has: a **short label** (e.g. “Job interview”, “Argument with boss”); optionally an **image** (upload or pick from a small set) or a **situation/memory in words** (free text). During BLS, the app can show the target label (and image if set) so the user knows what to hold in mind.
- [ ] **AC-007**: Targets are optional: user can run a session without naming a target (generic “calm” or “stress relief” focus).
- [ ] **AC-008**: Optional **distress rating** (0–10) for a target, for user’s own tracking only; no clinical interpretation in-app beyond an optional reminder that 7+ suggest professional support (can reuse F-0004-style copy).

### Configuration and safety
- [ ] **AC-009**: Session parameters are configurable: number of BLS sets, duration per set (or passes), minimum break duration. Sensible defaults (e.g. 3 sets, 45 s per set, 15 s min break).
- [ ] **AC-010**: User can exit the session early (e.g. “End session” during break or BLS) and is taken to closure or main screen without data loss.

---

## Out of Scope (for this feature)
- Full 8-phase EMDR protocol (therapist-only).
- Persistent storage of targets or session history (can be a later feature).
- Audio bilateral stimulation (visual only for now).
- Clinical assessment or treatment recommendations.

---

## Implementation notes
- Stages can be modeled as a linear sequence: `Preparation | BLS | Break | BLS | Break | … | Closure`.
- Target = `{ id, label, imageUrl?: string, note?: string, distress?: number }`.
- Reuse existing moving target components and speed presets; session mode orchestrates when they run and when to show break/closure UI.
