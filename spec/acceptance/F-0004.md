# F-0004: Screen-size–dependent instructions - Acceptance Criteria

**Feature**: On-screen instructions for self-EMDR that adapt to screen size so users optimize eye movement range (distance and posture) for desktop, tablet, and phone.

---

## Tests

### Unit Tests
- [ ] At least two instruction variants exist (e.g. “desktop/large screen” vs “phone/tablet”).
- [ ] Correct variant is shown based on viewport width (e.g. breakpoints at 768 px and/or 1024 px) or device class.
- [ ] Instructions mention distance (e.g. “sit slightly closer than the width of the screen”) for large screens and “hold device in landscape, close enough for comfortable eye movement” for small.

### Integration / E2E (if applicable)
- [ ] Resizing browser from desktop to mobile width switches instruction set; no stale “desktop” text on phone.
- [ ] Instructions are readable and not truncated on narrow viewports.

---

## Acceptance Criteria

### Desktop / large screen
- [ ] **AC-001**: For large viewports (e.g. ≥ 768 px or 1024 px), instructions state: sit at a distance slightly less than the width of the screen to maximize eye movement range; keep screen center at eye level; keep head still and move only eyes.

### Mobile / tablet
- [ ] **AC-002**: For small viewports (e.g. < 768 px), instructions state: use landscape orientation; hold device close enough that eye movements are as large as is comfortable; keep head still and move only eyes; center of screen at eye level when possible.

### Common (all sizes)
- [ ] **AC-003**: Instructions include: follow the moving target smoothly with your eyes; breathe naturally; typical use 2–5 minutes or until calmer. Optional: distress 1–6 is appropriate for self-practice; 7+ suggest professional support.
- [ ] **AC-004**: Instructions are visible before or at the start of a session (e.g. first-run or “Instructions” control) and can be reopened without restarting the target.

### Behavior
- [ ] **AC-005**: Instruction set is chosen from actual viewport/device size (or explicit user choice “I’m on phone” / “I’m on desktop”), not from a single fixed string for all devices.
