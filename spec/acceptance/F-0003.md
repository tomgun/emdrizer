# F-0003: Adjustable speed and research-based presets - Acceptance Criteria

**Feature**: User-adjustable speed of the moving target (Hz) and at least three research-based presets aligned with EMDR literature (processing / standard / resource).

---

## Tests

### Unit Tests
- [ ] Preset “Processing” (fast) maps to ~1.0–1.2 Hz (cycles per second).
- [ ] Preset “Standard” maps to 1 Hz.
- [ ] Preset “Resource” (slow) maps to a value in 0.2–0.5 Hz range.
- [ ] Custom speed, when implemented, correctly changes period of one full left–right–left cycle.
- [ ] Selected preset or custom value is applied to both KITT (F-0001) and therapist-finger (F-0002) views.

### Integration / E2E (if applicable)
- [ ] User can select a preset and see the on-screen target speed change.
- [ ] If custom speed control exists, min/max bounds prevent unsafe or ineffective values (e.g. 0.1–2 Hz).

---

## Acceptance Criteria

### Research-based presets
- [ ] **AC-001**: **Processing (fast)** preset: ~1.0–1.2 Hz. Label or tooltip references use for processing aversive memories (research: fast BLS for reprocessing).
- [ ] **AC-002**: **Standard** preset: 1 Hz. Label or tooltip references standard clinical EMDR frequency (~24 s sets in literature).
- [ ] **AC-003**: **Resource / Calm** preset: in 0.2–0.5 Hz range (e.g. 0.3 Hz). Label or tooltip references resource installation / calming (research: slow BLS for RDI).

### Adjustable speed
- [ ] **AC-004**: User can change speed (preset and/or custom) while a session is running; target motion updates without requiring a full page reload.
- [ ] **AC-005**: If custom speed is offered, it is constrained to a safe range (e.g. 0.1–2 Hz) and displayed in Hz or “cycles per second”.

### Consistency
- [ ] **AC-006**: Same speed and presets apply to both KITT view (F-0001) and therapist finger view (F-0002).

---

## Out of Scope
- Session duration or set length (e.g. 24 s); can be added later.
- Clinical protocol (phases, scripting); app is for self-practice target only.
