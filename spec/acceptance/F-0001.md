# F-0001: KITT car light target view - Acceptance Criteria

**Feature**: A moving eye target that mimics the KITT (Knight Rider) scanner: a single bright element sweeping left–right and back in a continuous loop, for self-administered EMDR bilateral stimulation.

---

## Tests

### Unit Tests
- [ ] Target position over time follows left–right sweep at configured frequency (Hz).
- [ ] Sweep is continuous (no visible jump at direction change).
- [ ] Visual matches “single moving light” (KITT style), not multiple dots.

### Integration / E2E (if applicable)
- [ ] View renders on web and on narrow (mobile) viewport; sweep spans usable width.

---

## Acceptance Criteria

### Core behavior
- [ ] **AC-001**: One clearly visible moving target (e.g. dot or short bar) moves horizontally across the screen.
- [ ] **AC-002**: Motion is a smooth back-and-forth sweep (left→right→left), like the KITT scanner.
- [ ] **AC-003**: Speed of the sweep is configurable (see F-0003); default matches “Standard” preset (1 Hz).
- [ ] **AC-004**: Target remains visible and readable on light and dark backgrounds (or user can choose theme).

### Accessibility / safety
- [ ] **AC-005**: No rapid flashing that could trigger photosensitivity; motion is smooth, not strobe-like.

---

## Out of Scope
- Speed presets and numeric control (covered by F-0003).
- Therapist finger view (F-0002).
- Screen-size instructions (F-0004).
