# F-0002: Therapist finger target view - Acceptance Criteria

**Feature**: A view showing a (blurred) therapist-style finger moving left–right as the eye-tracking target, for a more natural, familiar EMDR experience.

---

## Tests

### Unit Tests
- [ ] Finger asset or animation is displayed and moves horizontally.
- [ ] Blur is applied so the finger is recognizable but not sharp (privacy/aesthetic).
- [ ] Movement timing respects the same speed/preset system as F-0001 (F-0003).

### Integration / E2E (if applicable)
- [ ] View works on mobile and desktop; finger scale/position adapts to viewport.

---

## Acceptance Criteria

### Core behavior
- [ ] **AC-001**: A finger (or finger-like) target is shown moving horizontally (left–right–left) as the sole tracking target in this view.
- [ ] **AC-002**: The finger is visually blurred (e.g. Gaussian or motion blur) so it is recognizable but not photo-realistic.
- [ ] **AC-003**: Speed of movement is configurable and consistent with F-0003 presets (e.g. Standard 1 Hz).
- [ ] **AC-004**: User can switch between this view and the KITT view (F-0001) without leaving the app.

### Consistency
- [ ] **AC-005**: Same speed control and presets apply to both KITT and therapist-finger views.

---

## Out of Scope
- Real video of a therapist (only stylized/blurred representation).
- Speed UI and presets (F-0003).
- Screen-size instructions (F-0004).
