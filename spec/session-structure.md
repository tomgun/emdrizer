# Therapy session structure (research summary)

Reference for F-0005 implementation. Not a formal ADR.

## EMDR 8 phases (full protocol – therapist-led)

1. **History & treatment planning** – Alliance, identify targets.
2. **Preparation** – Explain process, coping techniques.
3. **Target assessment** – Specific event: image, beliefs, feelings, sensations; SUD/VOC baseline.
4. **Desensitization** – Bilateral stimulation while focusing on target until distress drops.
5. **Installation** – Strengthen positive belief.
6. **Body scan** – Hold target + positive belief, scan body, process residue.
7. **Closure** – Return to calm state.
8. **Reevaluation** – Next session: review, plan.

## Self-app / safe at-home (simplified)

- **Target**: Memory, thought, emotion, or situation – user gives a brief name; optional distress 0–10.
- **Sets**: 5–6 passes (left–right–left) per set, then check-in; 10–20 possible but stop if distress.
- **Breaks**: Between sets; “take a breath”, continue when ready.
- **Session length**: Often 5–15 minutes; timer optional.
- **Safe range**: Distress 1–6 appropriate for self-practice; 7+ suggest professional support.

## App session flow (F-0005)

- **Preparation** → set intention; optional target (label ± image/note).
- **BLS sets** → moving target for N seconds (or M passes); then **break** (pause, “Continue” when ready).
- **Closure** → “Session complete”, return to main.

Targets are optional; user can run “generic” calm/stress-relief without naming a memory.
